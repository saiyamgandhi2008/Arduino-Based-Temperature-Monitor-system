# Arduino-Based-Temperature-Monitor-system
This project implements an embedded temperature sensing station that reads thermal levels via an analog sensor and renders real-time readings on a 16x2  (LCD). When the measured temperature exceeds a defined threshold of 25°C, a visual alert is immediately triggered by illuminating an indicator LED.
